Java Lab Experiments extracted from Athin_Record.pdf

Experiments included:
02 - Caesar, Vigenere and Hill Ciphers
03 - One-Time Pad (OTP)
04 - Feistel Network
05 - Data Encryption Standard (DES)
06 - Triple DES (3DES)
07 - Advanced Encryption Standard (AES)
08 - Miller-Rabin Primality Test
09 - RSA Encryption

Each experiment is a standalone Java source file with its own main method.
PDF-induced source-code line wraps were repaired. The programs were compiled and run successfully.

To compile all programs:
    javac *.java

To execute an individual experiment, for example:
    java Exp02ClassicalCiphers

Note: The cryptography examples are educational, not production security implementations.
